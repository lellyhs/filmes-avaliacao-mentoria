# Desafio de Lógica: Classificação de Filmes

Este repositório contém a resolução do exercício final do módulo de lógica da Mentoria de Testes de Software. O objetivo do projeto é calcular o total de votos, a média das notas e indicar a recomendação de um filme.

## 🚀 Tecnologias Utilizadas

- **Node.js** (versão 18+)
- **Mocha** (Framework de Testes)
- **Assert** (Módulo nativo do Node.js para validações)

## 📁 Estrutura do Projeto

- `src/classificacao.js`: Arquivo com a função que contém a regra de negócio e cálculo da média.
- `test/classificacao.spec.js`: Arquivo com os cenários de testes automatizados unitários.

## 🔧 Como Executar o Projeto

1. Baixe ou clone este repositório.
2. Abra o terminal na pasta do projeto e instale as dependências:
   ```bash
   npm install
   ```
3. Execute os testes automatizados com o comando:
   ```bash
   npm test
   ```
